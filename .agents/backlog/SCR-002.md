## Description

Tokenizer that converts raw strategy script text into a flat sequence of tokens. Handles keywords, identifiers, numeric literals, operators, and delimiters.

## Requirements

- Define `enum Token`:
  - Keywords: `If`, `Else`, `Buy`, `Sell`
  - Literals: `Number(f64)`, `Identifier(String)`
  - Operators: `Plus`, `Minus`, `Star`, `Slash`, `Lt`, `Gt`, `Lte`, `Gte`, `EqEq`, `BangEq`, `And`, `Or`, `Assign`
  - Delimiters: `LParen`, `RParen`, `LBrace`, `RBrace`, `Comma`, `Semicolon`
  - `Eof`
- Implement `fn tokenize(input: &str) -> Result<Vec<Token>, ScriptError>`:
  - Skip whitespace and comments (lines starting with `//`)
  - Parse multi-character operators: `<=`, `>=`, `==`, `!=`, `&&`, `||`
  - Parse numeric literals (integers and decimals): `42`, `3.14`
  - Parse identifiers and match against keyword table
  - Return `ScriptError::LexError` for unrecognized characters with position
- Token derives `Debug`, `Clone`, `PartialEq`

## Acceptance Criteria

- [x] `tokenize("if rsi(14) < 30 { buy() }")` produces correct token sequence
- [x] `tokenize("sma(20) >= ema(50)")` correctly tokenizes `>=` as `Gte`
- [x] `tokenize("price <= 100.5")` handles decimal numbers
- [x] `tokenize("// comment\nbuy()")` skips comments
- [x] Unrecognized character `@` returns `LexError` with position
- [x] Empty input returns `[Eof]`
- [x] File stays under 250 lines

## Description

Configurable fee model and slippage calculator for the paper trading simulation. Separated from the matching engine for SRP — the engine calls into this module to compute execution costs.

## Requirements

- Define `struct FeeSchedule`:
  - `maker_rate: f64` (e.g., 0.001 for 0.1%)
  - `taker_rate: f64` (e.g., 0.001 for 0.1%)
  - `fee_asset: String` (e.g., "USDT")
- Implement `FeeSchedule::new(maker_rate: f64, taker_rate: f64, fee_asset: String) -> Result<Self, EngineError>` — validate rates are non-negative and < 1.0
- Implement `fn compute_fee(&self, notional: f64, is_maker: bool) -> f64`
- Define `struct SlippageModel`:
  - `base_bps: f64` (basis points, e.g., 5.0 = 0.05%)
- Implement `SlippageModel::new(base_bps: f64) -> Result<Self, EngineError>`
- Implement `fn apply_slippage(&self, price: f64, side: Side) -> f64`:
  - Buy → price * (1 + bps/10000)
  - Sell → price * (1 - bps/10000)

## Acceptance Criteria

- [ ] `compute_fee` with 0.1% rate on $10,000 notional = $10.00
- [ ] `apply_slippage` increases buy price and decreases sell price
- [ ] Negative fee rate returns `Err`
- [ ] Fee rate >= 1.0 returns `Err`
- [ ] Zero slippage returns the original price
- [ ] All items have `///` doc comments

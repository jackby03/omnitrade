## Description

Wire all script modules together and provide a convenience `compile_and_run` function.

## Requirements

### `src/lib.rs`
- Module declarations: `error`, `ast`, `lexer`, `parser`, `evaluator`
- Public re-exports:
  - `pub use error::ScriptError`
  - `pub use ast::{Expr, Stmt, BinaryOp, Signal}`
  - `pub use lexer::{Token, tokenize}`
  - `pub use parser::parse`
  - `pub use evaluator::Evaluator`
- Convenience function:
  ```rust
  pub fn compile_and_run(script: &str, candles: &[Candle]) -> Result<Signal, ScriptError>
  ```
  Combines tokenize → parse → evaluate in a single call.

## Acceptance Criteria

- [ ] `cargo check -p omnitrade-script` compiles
- [ ] `compile_and_run("if close() > 50000 { sell() }", &candles)` works end-to-end
- [ ] All re-exported types are accessible as `omnitrade_script::TypeName`
- [ ] Doc comment on `lib.rs` describing the crate's purpose

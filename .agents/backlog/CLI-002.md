## Description

The core backtesting loop: load candle data from CSV, compile a strategy script, and simulate trading through the matching engine.

## Requirements

- Define `struct BacktestConfig`:
  - `script_path: PathBuf`
  - `data_path: PathBuf`
  - `initial_balance: f64`
  - `fee_rate: f64`
  - `slippage_bps: f64`
- Define `struct BacktestResult`:
  - `total_pnl: f64`
  - `total_trades: usize`
  - `win_rate: f64`
  - `max_drawdown: f64`
  - `final_balance: f64`
- Implement `fn load_candles_csv(path: &Path) -> Result<Vec<Candle>, Box<dyn Error>>`:
  - Parse CSV with columns: `timestamp_ms,open,high,low,close,volume`
  - Use `csv` crate
- Implement `fn run_backtest(config: &BacktestConfig) -> Result<BacktestResult, Box<dyn Error>>`:
  - Load candles from CSV
  - Load and compile script from file (`std::fs::read_to_string` + `compile_and_run`)
  - For each candle window: evaluate script → if Buy/Sell signal → create order → process through matching engine
  - Track equity curve for max drawdown calculation
  - Return `BacktestResult`

## Acceptance Criteria

- [ ] CSV with 5 rows parses into 5 `Candle` structs
- [ ] Malformed CSV row returns error (not panic)
- [ ] Backtest with "always buy" script on rising prices produces positive PnL
- [ ] Backtest with "always sell" script on rising prices produces negative PnL
- [ ] `win_rate` is correctly computed as wins / total_trades
- [ ] File stays under 250 lines

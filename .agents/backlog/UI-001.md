## Description

Thread-safe UI state container that subscribes to broadcast channels from the engine and stores the latest market snapshots for rendering. The UI is a **passive subscriber** — it never mutates engine state.

## Requirements

- Define `struct UIState`:
  - `candles: HashMap<String, Vec<Candle>>` — per-symbol candle history
  - `orderbook: HashMap<String, L2OrderBook>` — per-symbol order book snapshot
  - `positions: HashMap<String, Position>` — current positions
  - `account_balance: f64`
  - `total_pnl: f64`
  - `connected: bool`
- Implement `UIState::new() -> Self`
- Implement `fn update_candle(&mut self, symbol: &str, candle: Candle)`
- Implement `fn update_orderbook(&mut self, symbol: &str, book: L2OrderBook)`
- Implement `fn update_account(&mut self, balance: f64, pnl: f64)`
- Implement `fn latest_candles(&self, symbol: &str, count: usize) -> &[Candle]`
- State must be wrapped in `Arc<RwLock<UIState>>` at the app level for cross-thread access

## Acceptance Criteria

- [x] `update_candle` appends to the symbol's candle vec
- [x] `latest_candles` returns at most `count` elements from the end
- [x] `latest_candles` for unknown symbol returns empty slice
- [x] State can be cloned and sent across threads (is `Send + Sync`)
- [x] No `.unwrap()` in production code
- [x] File stays under 250 lines

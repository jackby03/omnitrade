## Description

Immediate-mode candlestick chart renderer using `egui`'s painter API. Implements viewport culling to only render candles visible on screen.

## Requirements

- Define `struct CandleChartWidget`:
  - `candles: Vec<Candle>` (snapshot from UIState)
  - `visible_range: Range<usize>` — indices of candles to render
  - `candle_width: f32` — pixel width per candle
  - `spacing: f32` — pixel gap between candles
- Implement `fn show(&mut self, ui: &mut egui::Ui)`:
  - Calculate visible area: `[scroll_offset, scroll_offset + viewport_width]`
  - **Viewport culling**: compute `start_idx` and `end_idx` from scroll position, render ONLY that slice
  - Draw price grid lines (horizontal) with labels
  - Draw time axis (horizontal) with labels
  - For each visible candle:
    - Green rect for bullish (close >= open), Red for bearish
    - Thin line (wick) from low to high
    - Body rect from open to close
  - Map price range → pixel Y using `lerp` between `min_price` and `max_price` of visible candles
- Implement `fn handle_scroll(&mut self, delta: f32)` — pan the chart

## Acceptance Criteria

- [ ] Bullish candles render in green, bearish in red
- [ ] Wicks extend from low to high
- [ ] Only candles within the visible range are rendered (viewport culling)
- [ ] Chart auto-scales Y axis to visible price range
- [ ] Scroll input pans the chart horizontally
- [ ] File stays under 250 lines

## Description

Portfolio state tracker that maintains account balance, open positions, and PnL calculations. Processes `OrderFill` events to update balances and positions.

## Requirements

- Define `struct AccountState`:
  - `balance: f64` — available cash balance
  - `initial_balance: f64` — starting balance for PnL calculation
  - `positions: HashMap<String, Position>` — open positions by symbol
  - `total_fees_paid: f64` — running fee total
- Implement `fn new(initial_balance: f64) -> Result<Self, EngineError>` — reject negative balance
- Implement `fn apply_fill(&mut self, fill: &OrderFill) -> Result<(), EngineError>`:
  - **Buy fill**: deduct `fill.notional() + fill.fee` from balance; create or increase position
  - **Sell fill**: add `fill.notional() - fill.fee` to balance; reduce or close position; compute realized PnL
  - Return `EngineError::InsufficientBalance` if balance would go negative
  - Accumulate `total_fees_paid`
- Implement `fn update_unrealized_pnl(&mut self, symbol: &str, current_price: f64) -> Result<(), EngineError>`:
  - Call `Position::mark_to_market()` for the given symbol
  - Return `EngineError::SymbolNotFound` if no position exists
- Implement `fn total_equity(&self) -> f64` — `balance + Σ(position.unrealized_pnl)`
- Implement `fn total_pnl(&self) -> f64` — `total_equity - initial_balance`
- Implement `fn get_position(&self, symbol: &str) -> Option<&Position>`

## Acceptance Criteria

- [x] Buy fill deducts correct amount (notional + fee) from balance
- [x] Sell fill adds correct amount (notional - fee) to balance
- [x] Buy + Sell at same price with fees results in negative PnL (fee drag)
- [x] `InsufficientBalance` returned when balance would go negative
- [x] `total_equity` includes unrealized PnL from all open positions
- [x] Position is removed from `positions` when fully closed (qty == 0)

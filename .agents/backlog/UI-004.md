## Description

Main `eframe::App` implementation that composes all widgets into a dockable workspace using `egui_tiles`.

## Requirements

### `src/app.rs`
- Define `struct OmniTradeApp`:
  - `state: Arc<RwLock<UIState>>`
  - `tree: egui_tiles::Tree<PanelKind>` — docking layout tree
  - `chart: CandleChartWidget`
  - `depth: DepthWidget`
- Define `enum PanelKind` — `Chart`, `OrderBook`, `Positions`, `Console`
- Implement `eframe::App for OmniTradeApp`:
  - `fn update(&mut self, ctx: &egui::Context, _frame: &mut eframe::Frame)`:
    - Read state snapshot from `Arc<RwLock<UIState>>`
    - Render the `egui_tiles::Tree` which dispatches to panel-specific widgets
    - Request repaint at target framerate (`ctx.request_repaint()`)
- Implement `egui_tiles::Behavior<PanelKind>` to route panel rendering

### `src/main.rs`
- Initialize `UIState` wrapped in `Arc<RwLock<>>`
- Create `OmniTradeApp` with default panel layout
- Launch `eframe::run_native()` with `NativeOptions` (GPU preferred)
- Set window title: "omnitrade"

## Acceptance Criteria

- [ ] Application launches a window titled "omnitrade"
- [ ] Docking workspace shows at least 2 panels (Chart + OrderBook)
- [ ] Panels are resizable and rearrangeable via egui_tiles
- [ ] App compiles with `cargo build -p omnitrade-ui`
- [ ] No `.unwrap()` in production code (use `.expect()` only for eframe init)

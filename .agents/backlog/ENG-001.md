## Description

Define domain error types and the `OrderFill` struct representing a completed (or partial) order execution event.

## Requirements

### `src/error.rs`
- Create `EngineError` enum using `thiserror`:
  - `InsufficientBalance { required: f64, available: f64 }`
  - `OrderNotFound { order_id: u64 }`
  - `InvalidOrderSize { size: f64, reason: &'static str }`
  - `SymbolNotFound { symbol: String }`
  - `AccountLocked { reason: String }`
  - `Core(#[from] omnitrade_core::CoreError)` — transparent propagation

### `src/fill.rs`
- Create `OrderFill` struct:
  - `order_id: u64`
  - `symbol: String`
  - `side: Side`
  - `fill_price: f64` (actual execution price after slippage)
  - `fill_quantity: f64`
  - `fee: f64`
  - `fee_asset: String` (e.g., "USDT")
  - `timestamp_ms: u64`
  - `is_maker: bool`
- Derive `Debug`, `Clone`, `PartialEq`
- Implement `fn notional(&self) -> f64` — `fill_price * fill_quantity`
- Implement `fn net_notional(&self) -> f64` — notional minus fee

## Acceptance Criteria

- [ ] `EngineError` implements `std::error::Error` and `Display`
- [ ] `EngineError::Core` variant enables transparent `?` propagation from `CoreError`
- [ ] `OrderFill::notional()` and `net_notional()` are tested
- [ ] All items have `///` doc comments

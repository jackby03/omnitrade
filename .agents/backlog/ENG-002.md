## Description

In-memory Level 2 order book representation using `BTreeMap` for sorted price levels. Includes a safe `OrderedFloat` wrapper that implements `Ord` for `f64` (required for `BTreeMap` keys), explicitly handling NaN as invalid.

## Requirements

### `OrderedFloat` wrapper (top of file, private)
- `struct OrderedFloat(f64)` implementing `Ord`, `Eq`, `Hash`
- Constructor `fn new(val: f64) -> Result<Self, EngineError>` — reject NaN/Infinity
- Implement `PartialOrd`, `PartialEq` using `f64::total_cmp()`

### `L2OrderBook`
- Fields:
  - `symbol: String`
  - `bids: BTreeMap<OrderedFloat, f64>` (price → quantity, reverse-sorted for bids)
  - `asks: BTreeMap<OrderedFloat, f64>` (price → quantity, natural sort for asks)
  - `last_update_ms: u64`
- Methods:
  - `fn new(symbol: String) -> Self`
  - `fn apply_delta(&mut self, bids: &[(f64, f64)], asks: &[(f64, f64)]) -> Result<(), EngineError>` — update levels; remove level if qty == 0.0
  - `fn best_bid(&self) -> Option<(f64, f64)>` — highest bid
  - `fn best_ask(&self) -> Option<(f64, f64)>` — lowest ask
  - `fn spread(&self) -> Option<f64>` — `best_ask.price - best_bid.price`
  - `fn mid_price(&self) -> Option<f64>` — `(best_ask + best_bid) / 2`
  - `fn depth_at(&self, price: f64) -> Option<f64>` — quantity at a price level

## Acceptance Criteria

- [x] `OrderedFloat::new(f64::NAN)` returns `Err`
- [x] Bids are sorted descending (best bid = highest price)
- [x] Asks are sorted ascending (best ask = lowest price)
- [x] `apply_delta` with qty=0.0 removes the price level
- [x] `spread()` returns `None` on empty book
- [x] `mid_price()` is tested with known bid/ask values

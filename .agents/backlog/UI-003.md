## Description

Dual-column order book depth visualization showing bid and ask levels with volume bars.

## Requirements

- Define `struct DepthWidget`:
  - `max_levels: usize` (default: 20)
  - `show_spread: bool`
- Implement `fn show(&self, ui: &mut egui::Ui, book: &L2OrderBook)`:
  - Render header row: "Price | Qty | | Qty | Price"
  - Render ask levels (top, sorted ascending): red bars proportional to volume
  - Render spread row: `"Spread: {spread} ({spread_pct}%)"`
  - Render bid levels (bottom, sorted descending): green bars proportional to volume
  - Volume bars use `ui.painter().rect_filled()` scaled relative to max volume in visible levels
  - Show cumulative volume column
- Implement `fn spread_percentage(book: &L2OrderBook) -> Option<f64>`:
  - `(best_ask - best_bid) / mid_price * 100.0`

## Acceptance Criteria

- [ ] Empty order book renders a placeholder message
- [ ] Bid bars are green, ask bars are red
- [ ] Volume bars scale relative to the maximum volume level
- [ ] Spread percentage is calculated correctly
- [ ] Widget respects `max_levels` limit
- [ ] File stays under 250 lines

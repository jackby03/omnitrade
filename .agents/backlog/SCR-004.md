## Description

AST evaluator that executes strategy scripts against market data buffers (candle arrays). Supports built-in indicator functions and produces trading signals.

## Requirements

- Define `struct Evaluator`:
  - `variables: HashMap<String, f64>` — user-defined variable bindings
- Implement `fn evaluate(&mut self, stmts: &[Stmt], candles: &[Candle]) -> Result<Signal, ScriptError>`:
  - Walk the AST, evaluate expressions, execute statements
  - Default signal is `Signal::Hold`
  - First `SignalBuy` or `SignalSell` encountered sets the result
- Implement `fn eval_expr(&mut self, expr: &Expr, candles: &[Candle]) -> Result<f64, ScriptError>`:
  - `Expr::Number(n)` → return `n`
  - `Expr::Identifier(name)` → look up in `variables`, return `ScriptError::UndefinedVariable` if missing
  - `Expr::BinaryOp` → evaluate both sides, apply operator. Comparisons return 1.0 (true) or 0.0 (false)
  - `Expr::FunctionCall` → dispatch to built-in functions:
    - `sma(period)` — compute SMA of close prices over last `period` candles
    - `rsi(period)` — compute RSI of close prices over last `period` candles
    - `ema(period)` — compute EMA of close prices
    - `close()` — return the latest candle's close price
    - `volume()` — return the latest candle's volume
  - Return `ScriptError::UndefinedFunction` for unknown functions
- Handle division by zero: return `ScriptError::EvalError`

## Acceptance Criteria

- [x] `evaluate("if rsi(14) < 30 { buy() }")` returns `Signal::Buy` when RSI < 30
- [x] `evaluate("if sma(10) > sma(20) { buy() } else { sell() }")` returns correct signal
- [x] `evaluate("x = close(); if x > 50000 { sell() }")` binds variable and evaluates
- [x] Undefined function `foo(1)` returns `ScriptError::UndefinedFunction`
- [x] Division by zero returns `ScriptError::EvalError`
- [x] Empty candle slice returns `ScriptError::EvalError`
- [x] File stays under 250 lines

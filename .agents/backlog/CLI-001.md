## Description

Command-line argument parsing for the headless backtesting runner using `clap`. Defines subcommands and initializes the application skeleton.

## Requirements

### `src/args.rs`
- Define `struct CliArgs` using `clap::Parser`:
  - Subcommand `backtest`:
    - `--script <PATH>` — path to strategy script file
    - `--data <PATH>` — path to candle CSV file
    - `--initial-balance <AMOUNT>` — starting balance (default: 10000.0)
    - `--fee-rate <RATE>` — taker fee rate (default: 0.001)
    - `--slippage-bps <BPS>` — slippage in basis points (default: 5.0)
  - Subcommand `validate`:
    - `--script <PATH>` — parse a script and report errors without executing

### `src/main.rs`
- Parse args with `CliArgs::parse()`
- Match on subcommand and print placeholder messages
- Use `Result<(), Box<dyn std::error::Error>>` as main return type

## Acceptance Criteria

- [ ] `omnitrade-cli backtest --help` prints usage info
- [ ] `omnitrade-cli validate --script foo.omni` parses without error
- [ ] Missing required args produce clear error messages (via clap)
- [ ] Default values are applied when optional args are omitted

## Description

Define the error types, Abstract Syntax Tree (AST) node types, and signal output enum for the omnitrade strategy DSL.

## Requirements

### `src/error.rs`
- Create `ScriptError` enum using `thiserror`:
  - `LexError { position: usize, message: String }`
  - `ParseError { token_index: usize, message: String }`
  - `EvalError { message: String }`
  - `UndefinedVariable { name: String }`
  - `UndefinedFunction { name: String }`
  - `TypeError { expected: String, got: String }`
  - `Core(#[from] omnitrade_core::CoreError)`

### `src/ast.rs`
- Define `enum BinaryOp` — `Add`, `Sub`, `Mul`, `Div`, `Gt`, `Lt`, `Gte`, `Lte`, `Eq`, `Neq`, `And`, `Or`
- Define `enum Expr`:
  - `Number(f64)`
  - `Identifier(String)`
  - `BinaryOp { left: Box<Expr>, op: BinaryOp, right: Box<Expr> }`
  - `FunctionCall { name: String, args: Vec<Expr> }`
  - `Negate(Box<Expr>)`
- Define `enum Stmt`:
  - `Assign { name: String, value: Expr }`
  - `If { condition: Expr, then_block: Vec<Stmt>, else_block: Option<Vec<Stmt>> }`
  - `SignalBuy`
  - `SignalSell`
  - `ExprStmt(Expr)` — standalone expression
- Define `enum Signal` — `Buy`, `Sell`, `Hold`
- All types derive `Debug`, `Clone`, `PartialEq`

## Acceptance Criteria

- [x] `ScriptError` implements `std::error::Error` and `Display`
- [x] AST can represent `if rsi(14) < 30 { buy() }` as nested nodes
- [x] `BinaryOp` covers all comparison and arithmetic operators
- [x] `Signal` has exactly three variants
- [x] All types have `///` doc comments
- [x] Combined file size of both files stays under 250 lines each
